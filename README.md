## 🌟 نبذة عن المشروع | About The Project

**منصة FRD** هي منصة ويب تعليمية وسريرية تفاعلية لطلبة وأطباء طب الأسنان. تساعد على تحويل محاضرات PDF وPowerPoint إلى تجربة دراسية تشمل الترجمة والتلخيص والاختبارات والمراجعة.

تجمع المنصة بين:
1. **الترجمة الطبية الذكية** (سطر بسطر أو فقرات كاملة) مع تصحيح المصطلحات السنية وفق المعايير الأكاديمية.
2. **محاذاة هندسية دقيقة 1:1 للسلايدات والرسومات** دون أي ترحيل أو فقدان للمعلومات أو الصور.
3. **الملخص الذكي المركز** الذي يوضح مباشرة عن ماذا تتحدث المحاضرة وما هي الفوائد السريرية والعملية منها دون حشو.
4. **تكامل مجاني مع ذكاء Google Gemini AI** لترجمة المحاضرات وشرحها وتوليد أسئلة الامتحانات.
5. **قاموس سني موسع** يضم أكثر من 1200 مصطلح سريري تخصصي في كافة فروع طب الأسنان.
6. **ألعاب التثبيت والاسترجاع النشط** (بطاقات استرجاع ثلاثية الأبعاد Flashcards ومطابقة مصطلحات سريعة متعددة الجولات).
7. **الاختبار المنهجي السريري** التفاعلي المتجدد مع شرح أسباب الإجابات الصحيحة.
8. **دعم كامل للمحاضرات باللغة العربية والإنجليزية**.

## ✨ المميزات الرئيسية | Key Features

### 🔤 1. نظام الترجمة المزدوج الفوري (سطر بسطر / فقرة كاملة)
- **وضع سطر بسطر (Line-by-Line):** ترجمة كل فكرة وسطر مباشرة أسفل النص الأصلي مع تمييز المصطلحات وإمكانية الاستماع لنطقها بالإنجليزية.
- **وضع الفقرة الكاملة (Full Paragraph):** ترجمة السياق العلمي الكامل للفقرة لربط الأفكار سريرياً دون الحاجة لإعادة رفع الملف.
- إمكانية إعادة ترجمة أي سطر بنقرة زر أو تعديل الترجمة يدوياً وحفظها تلقائياً.

### 🖼️ 2. استعراض السلايدات والرسومات بدقة فائقة (1:1 HD Canvas)
- ربط دقيق وحتمي بين كل صفحة في ملف الـ PDF/PPTX وصورتها ونصها الأصلي وترجمتها، مما يمنع نهائياً ترحيل أو تخطي السلايدات.
- تصيير عالي الدقة لجميع المخططات، صور الأشعة، والرسومات مع ميزة التكبير (Lightbox Zoom).

### 💡 3. الملخص الذكي المركز
- يقدم إجابة مباشرة عن:
  - 🎯 **عن ماذا تتحدث المحاضرة؟**: نبذة موجزة وسريعة في سطرين إلى ثلاثة فقط.
  - 🩺 **ماذا ستستفيد من المحاضرة سريرياً؟**: 3 إلى 5 نقاط عملية سريعة وقابلة للتطبيق.

### 📖 4. القاموس السني التخصصي (1200+ مصطلح)
- يغطي: تعويضات الأسنان (Prosthodontics)، المعالجة اللبية (Endodontics)، جراحة الفم (Oral Surgery)، أمراض اللثة (Periodontics)، المواد السنية (Dental Materials)، أنسجة الفم (Oral Histology)، تقويم الأسنان، وطب أسنان الأطفال، وترقيم الأسنان الدولي FDI.
- بحث فوري باللغتين ونطق صوتي وتحليل مورفولوجي للسوابق واللواحق الطبية.

### 🧠 5. الاختبار المنهجي وبنك الأسئلة المتجدد
- توليد اختبارات سريرية مخصصة لكل محاضرة تتغير في كل مرة (7، 10، 15، أو 20 سؤالاً).
- شروحات سريرية للإجابات، مع مؤقت إلكتروني وحساب دقيق للنسبة المئوية.

### ⚡ 6. ألعاب التثبيت والاسترجاع النشط
- **بطاقات الاسترجاع (Flashcards):** بطاقات ثلاثية الأبعاد قابلة للقلب تغطي كافة مصطلحات وأفكار المحاضرة.
- **مطابقة المصطلحات السريعة:** تحديات زمنية بجولات متعددة لترسيخ المصطلحات في الذاكرة طويلة المدى.

### ✨ 7. تكامل الذكاء الاصطناعي المجاني (Google Gemini AI)
- فعّل Gemini من زر الإعدادات في المنصة، وأنشئ مفتاحاً من [Google AI Studio](https://aistudio.google.com/app/apikey). عند تفعيله يستخدم للترجمة والتلخيص وتوليد الأسئلة.
- الحصة المجانية وحدودها وتوفر النموذج تخضع لشروط Google وقد تتغير؛ لا ترفع بيانات مرضى أو معلومات سرية. يُحفظ المفتاح في المتصفح ويُرسل مباشرة إلى Google.
- عمل المنصة محلياً 100% بكفاءة وسرعة فائقة حتى دون الحاجة للذكاء الاصطناعي.

## 🚀 كيفية التثبيت والتشغيل محلياً | Quick Start

### المتطلبات الأساسية:
- تثبيت [Node.js](https://nodejs.org) (الإصدار 18 فما فوق).

### خطوات التشغيل:
1. استنسخ المستودع أو فك الضغط عن مجلد المشروع:
```bash
git clone https://github.com/<your-username>/FRD.git
cd FRD
```

2. تثبيت الحزم التابعة:
```bash
npm install
```

3. تشغيل المنصة في وضع التطوير المحلي:
```bash
npm run dev
```
افتح المتصفح على الرابط: `http://localhost:5173`

4. بناء النسخة الإنتاجية (Production Build):
```bash
npm run build
```

## 📁 هيكلية المشروع | Project Structure

```
lablabi/
├── public/                 # الأيقونات والوسائط الثابتة
├── src/
│   ├── components/
│   │   ├── canvas/         # عارض السلايدات والترجمة سطر بسطر والفقرات
│   │   ├── common/         # النوافذ والمودالات ومؤشرات التحميل وإعدادات Gemini
│   │   ├── dictionary/     # القاموس السني الموسع
│   │   ├── engine/         # لوحة قياسات المحرك والأمانة العلمية
│   │   ├── exam/           # محرك الاختبارات السريرية المنهجية
│   │   ├── games/          # ألعاب التثبيت (Flashcards والمطابقة السريعة)
│   │   ├── layout/         # شريط التنقل والخلفيات التفاعلية
│   │   ├── library/        # مكتبة المحاضرات المحفوظة محلياً
│   │   └── translation/    # نافذة الترجمة السريعة والبحث
│   ├── context/            # إدارة الحالة (CoreEngine, Theme, User)
│   ├── services/
│   │   ├── geminiService.js       # تكامل Google Gemini AI المجاني
│   │   ├── pdfService.js          # تصدير وطباعة PDF
│   │   ├── processingEngine.js    # محرك التفكيك والربط المنهجي 1:1
│   │   ├── storageService.js      # التخزين المحلي في IndexedDB
│   │   └── translationService.js  # محرك الترجمة والقاموس السني (1200+ مصطلح)
│   ├── styles/             # التنسيقات والسمات والمتغيرات البصرية
│   └── App.jsx             # الحاوية الرئيسية للمنصة
├── package.json

```
